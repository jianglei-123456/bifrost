# Triage 标签

各技能用五个规范 triage 角色说话，本文件把角色映射到本仓库追踪器里实际使用的标签字符串。

| 技能中的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整规格化，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到某个角色（如「打上 AFK-ready triage 标签」）时，用本表对应的标签字符串。本地 markdown 追踪器把它记作 issue 文件里的 `Status:` 值。
