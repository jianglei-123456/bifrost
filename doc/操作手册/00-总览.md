## 1. 手册定位

本手册面向**部署与使用 Bifrost 的人**（家庭用户 / 运维），解决"怎么跑起来、怎么把音乐和电子书塞进去、怎么让手机和电脑上的播放器/阅读器连上来"三类问题。它是操作层面的指南，**不涉及内部实现**——实现细节见《整体技术架构》与《音乐管理技术设计》，协议细节见《Subsonic_API_参考》。

适用版本：**1.0.0**（里程碑 M1 音乐管理 + Subsonic 兼容协议服务 Syrinx；M2-book 图书管理 + OPDS 1.2 发布；M3-sync 阅读进度同步 KOSync），交付形态为**单镜像**（管理端挂 `/admin/`，见 [05](05-Docker部署.md)）。

## 3. 三分钟快速上手

1. **启动**：设置初始密码并启动应用（本地运形态见 [01](01-安装与启动.md) §3；容器形态见 [05](05-Docker部署.md) §3）：

   ```bash
   BIFROST_AUTH_INITIAL_PASSWORD=你的密码 ./mvnw -pl bifrost-bootstrap -am spring-boot:run
   ```

2. **打开管理端**：浏览器访问 `http://<Bifrost主机IP>:18080/`（会 302 到 `/admin/`）→ 用上一步的口令登录。

3. **建库并扫描**：管理端「音乐库」新建音乐目录（容器里填 `/media/music`，本机填绝对路径），触发一次扫描。此后每天 03:00 定时增量扫描。

4. **连接客户端**：在 Feishin / DSub / Symfonium / play:Sub 等客户端中填写：

   - 服务器地址：`http://<Bifrost主机IP>:18080`（部分客户端末尾补 `/rest`，详见 [02](02-连接Subsonic客户端.md)）
   - 用户名：`admin`
   - 密码：步骤 1 设置的初始密码

   然后浏览、搜索、播放即通。分客户端字段对照见 [02](02-连接Subsonic客户端.md) §4。

5. **（图书，可选）** 建图书目录并扫描，再在阅读器里添加 OPDS 目录：

   - 建目录与扫描（curl 见 [04](04-连接阅读器客户端.md) §1）；添加 Readest/KOReader 时填完整目录根 URL：`http://<Bifrost主机IP>:18080/opds/v1.2/catalog`（不是 `/opds`）。
   - 分客户端步骤见 [04](04-连接阅读器客户端.md) §4。

6. **（阅读进度，可选）** 管理端「阅读进度」拿同步账号，在 KOReader 的 *Progress sync → Custom sync server* 填 `http://<Bifrost主机IP>:18080`，见 [04](04-连接阅读器客户端.md) §7。
