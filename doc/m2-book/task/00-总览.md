# M2-book 里程碑任务总览（图书管理 + OPDS 发布）

| 项 | 内容 |
| --- | --- |
| 里程碑 | M2-book（mini-milestone，**仅图书侧**） |
| 本轮范围 | 图书导入 + 元数据处理 + OPDS 1.2 协议分发 + 管理 REST；**不含**进度同步 / WebDAV / OPDS-PSE / 多用户 |
| 依据 | 调研档 `doc/m2-book/调研/00-索引.md`、ADR-0004、CONTEXT.md（增补后） |
| 交付形态 | 分 5 个任务阶段推进，每阶段可编译、可测试、可提交；最终一次交付完整 M2-book |

## 1. 验收标准

1. 扫描 EPUB（`.epub` / `.kepub.epub`）/ PDF（`.pdf`）目录建库，形成「Book 单层 + LibraryRoot（按 mediaType=BOOK 隔离）」索引；
2. KOReader（设备端）和 Readest（PC/Web 端）可连接、浏览、搜索、下载图书；
3. 管理 REST（`/api/books` / `/api/book-roots`）可用（统一信封、认证、分页）；
4. 管理端可编辑图书元数据（不写回文件）和替换封面；
5. 文档齐备：任务文档 + ADR + hurl 契约测试 + 构建全绿。

## 2. 阶段与依赖

```
01 图书核心 ──► 02 OPDS 发布 ──► 04 测试与收尾
        │            │
        └──► 03 管理 REST ──┘
05 延后项（Day-one 不做的清单）
```

- 01 → 02、01 → 03：实体、扫描、cover 抽取是 OPDS 和管理 REST 的共同依赖；
- 02 → 04、03 → 04：OPDS 契约测试 + 管理 REST 契约测试；
- 每阶段完成标准：`./mvnw -pl <模块> -am compile` 通过 + 该阶段测试通过 + git 提交。

## 4. 技术栈与依赖增量

| 依赖 | 版本 | 说明 |
|---|---|---|
| `com.positiondev.epublib:epublib-core` | 3.1 | EPUB OPF/NCX/cover 解析（Central 可达） |
| `org.apache.pdfbox:pdfbox` | 3.0.x | PDF InfoDict + XMP 解析（**不渲染首页**） |
| 现有所有 music 依赖 | — | 完全复用（Spring Boot 3.5.16 / Java 21 / SQLite / JPA） |

**不引入**：
- `nl.siegmann.epublib:epublib-core`（Maven Central 不在）
- `io.documentnode:epublib`（备选，本轮不引入）
- Apache Tika（重量级；EPUB 内部也委托给 epublib）
- EPUBCheck（验证器而非提取器；Day-one 不引入）
- Calibre CLI 依赖（避免外部进程依赖；后续如要 PDF 封面渲染再考虑）

## 5. 与 M1 的边界

| 共享 | 隔开 |
|---|---|
| `bifrost-common`（Fingerprint、Strings、FileIO、BizException、Dates） | `book_*` 表 vs `track/album/artist` 表（物理） |
| `bifrost-domain`（BaseEntity、MediaType 枚举扩 BOOK 实例、LibraryRoot 加 mediaType 列） | `BookScanService` vs `ScanService`（独立 ReentrantLock） |
| `bifrost-core` 内的 `com.bifrost.core.book` 包 | `com.bifrost.core.book.BookScanCompletedEvent`（新事件） |
| `bifrost-bootstrap` 跨模块扫描（无改动） | `/api/book-roots/scan/*` vs `/api/scan/*`（独立端点） |
| `bifrost-bootstrap/security`（Spring Security 复用） | `/opds/v1.2/...` vs `/rest/...`（独立路由 + 默认匿名） |

## 6. 常用命令

```bash
./mvnw -pl bifrost-bootstrap -am clean verify              # 全量

hurl --test hurl/opds/*.hurl                                # OPDS 契约
```
