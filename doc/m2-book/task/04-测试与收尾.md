## 1. hurl 契约测试

### 1.1 端点覆盖

| 文件 | 端点 | 关键断言 |
|---|---|---|
| `hurl/opds/catalog.hurl` | `GET /opds/v1.2/catalog` | status 200; `Content-Type` 包含 `profile=opds-catalog;kind=navigation`; 含 `<title>Bifrost 图书库</title>`; 含 2 个 `<entry>`（all + recent）; 含 `rel="search"` link |
| `hurl/opds/all.hurl` | `GET /opds/v1.2/catalog/all?page=1&count=10` | status 200; `kind=acquisition`; 含 `opensearch:totalResults`; 含 ≥1 个 `<entry>`; 每个 entry 含 `rel="http://opds-spec.org/acquisition"` link |
| `hurl/opds/recent.hurl` | `GET /opds/v1.2/catalog/recent` | status 200; 含 `rel="http://opds-spec.org/sort/new"` link; entry 按 `updated` 降序 |
| `hurl/opds/search.hurl` | `GET /opds/v1.2/search?q=...` | status 200; acquisition feed; totalResults ≤ all.hurl totalResults |
| `hurl/opds/search-osdd.hurl` | `GET /opds/v1.2/search.xml` | status 200; `application/opensearchdescription+xml`; 含 `<Url template="...{searchTerms}...">` |
| `hurl/opds/file.hurl` | `GET /opds/v1.2/catalog/{bookId}/file` | status 200; `Content-Type=application/epub+zip` 或 `application/pdf`; `Accept-Ranges: bytes`; `Content-Length` 与 DB 一致 |
| `hurl/opds/file-range.hurl` | `GET /opds/v1.2/catalog/{bookId}/file`（带 Range: bytes=0-1023） | status 206; `Content-Range: bytes 0-1023/<total>`; body 长度 = 1024 |
| `hurl/opds/cover.hurl` | `GET /opds/v1.2/catalog/{bookId}/cover` | status 200; `Content-Type=image/jpeg`; body 前 3 字节 = `FF D8 FF`（JPEG magic） |
| `hurl/opds/cover-missing.hurl` | `GET /opds/v1.2/catalog/{noCoverBookId}/cover` | status 404 |
| `hurl/opds/auth.hurl` | `GET /opds/v1.2/catalog`（`require-auth=true` 时） | 无 Authorization → 401; 带正确 Basic → 200 |

### 1.2 hurl 公共变量

`hurl/opds/_setup.hurl`（用 `[Options]` include）：
```hurl
[Options]
variable: base_url=http://localhost:8080
```

每个 hurl 文件：
```hurl
# 共享变量 + 鉴权
GET {{base_url}}/opds/v1.2/catalog
HTTP 200
[Headers]
Content-Type: application/atom+xml;profile=opds-catalog;kind=navigation
[Asserts]
xpath "string(//atom:feed/atom:title)" == "Bifrost 图书库"
xpath "count(//atom:feed/atom:entry)" >= 2
xpath "//atom:feed/atom:link[@rel='search']/@type" contains "opensearchdescription+xml"
```

### 1.3 管理 REST hurl

`hurl/api/book-roots.hurl`：
```hurl
# 鉴权：admin/admin
GET {{base_url}}/api/book-roots
HTTP 200
[BasicAuth]
admin: admin
[Asserts]
jsonpath "$.code" == 0
jsonpath "$.data.items" isCollection
```

`hurl/api/books.hurl`：
```hurl

```

`hurl/api/books-cover.hurl`：

## 2. 集成测试（Java）

`bifrost-bootstrap/src/test/java/.../BookScanIntegrationTest.java`：

```java
@SpringBootTest(webEnvironment = WebEnvironment.RANDOM_PORT)
@AutoConfigureMockMvc
@TestPropertySource(properties = {
    "bifrost.library.roots[0].path=${java.io.tmpdir}/bifrost-test-book",
    "bifrost.library.roots[0].media-type=BOOK",
    "bifrost.db.path=${java.io.tmpdir}/bifrost-test.db"
})
class BookScanIntegrationTest {
    @Autowired BookScanService bookScanService;
    @Autowired BookRepository bookRepository;

    @Test
    void scanEpubFromFixture() throws Exception {
        // 拷贝 data-sample/ebook/*.epub 到 tmp 路径
        // 触发扫描
        BookScanStats stats = bookScanService.scanAll(false);
        assertThat(stats.inserted()).isGreaterThan(0);
        assertThat(bookRepository.findAll())
            .extracting(Book::getFormat)
            .contains("EPUB");
    }
}
```

## 3. `data-sample/ebook/` Fixture 选型

**Day-one 入选清单**（公开域 + 体积小 + 跨语言覆盖）：

| 文件 | 来源 | 类型 | 用途 |
|---|---|---|---|
| `pride-and-prejudice.epub` | Project Gutenberg #1342 | EPUB / 英文 | 主标题 + 多作者（仅 1 位）解析验证 |
| `tao-te-ching.epub` | Project Gutenberg #216 或 Standard Ebooks | EPUB / 中文（**备选**：公开域中文 EPUB 较少，可能用 Gutenberg 中文版） | 中文 `dc:language` + 中文字符 title 解析 |
| `two-formats-test.epub` | 自制（同一内容两格式） | EPUB | 验证 Q13 不匹配（同书多文件 = 两条 Book） |
| `sample.pdf` | Public Domain PDF（如 Gutenberg PDF 版） | PDF | PDF parser 验证（XMP 优先 + InfoDict fallback） |
| `cover-test.jpg` | 自制 800×600 JPEG | 封面图 | 上传封面测试 |

**所有文件** ≤ 5 MB，git 入库。选型时**避免版权问题**——只用 Project Gutenberg / Standard Ebooks / Public Domain 来源。

> **Day-one 选型若中文 EPUB 难找**：先用英文 EPUB 跑通 + 一本英文 PDF，**中文场景留作 Day-two 增强**。本里程碑不阻塞。
