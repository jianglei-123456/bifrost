# 06 前端对接（Vue Dashboard 接口契约）

> 范围：M2-book mini-milestone 前端落地清单。Bifrost 后端不包含 Vue Dashboard 代码（独立项目），
> 本档列出 Vue Dashboard（M1 已有的项目）需要新增的页面 / 组件 / 状态 / 端点消费。

## 1. 后端提供的端点（已实现 + 已通过 hurl 契约测试）

### 1.1 图书库根管理 `/api/book-roots`

| 方法 | 路径 | 请求体 | 响应 | 用途 |
|---|---|---|---|---|
| GET | `/api/book-roots` | — | `ApiResponse<List<BookRootDto>>` | 列出**全部** BOOK 库根（含停用，ID 升序——前端需"启用"开关可往返；Q25 后端改动，mediaType 参数不再接受，恒 BOOK） |
| POST | `/api/book-roots` | `{name, path, enabled?: bool}` | `ApiResponse<BookRootDto>` | 新建 BOOK 库根（mediaType 强制 BOOK，忽略请求体） |
| GET | `/api/book-roots/{id}` | — | `ApiResponse<BookRootDto>` | 详情 |
| PATCH | `/api/book-roots/{id}` | `{name?, path?, enabled?}` | `ApiResponse<BookRootDto>` | 部分更新（**不**允许改 mediaType） |
| DELETE | `/api/book-roots/{id}` | — | `ApiResponse<Void>` | 删除（级联 Book.isAvailable=false） |
| POST | `/api/book-roots/{id}/scan?force=false` | — | `ApiResponse<{scanStatus, rootId, message}>` | **异步**触发扫描，立即返回 SCANNING |
| POST | `/api/book-roots/scan/all?force=false` | — | `ApiResponse<{scanStatus, rootId, message}>` | 异步触发所有 BOOK 根扫描 |
| GET | `/api/book-roots/scan/status` | — | `ApiResponse<BookScanStatusView>` | 全局 BOOK 扫描状态（currentRootId + lastStats） |

**BookRootDto**：
```json
{
  "id": 1,
  "name": "测试图书库",
  "path": "E:/testbook",
  "enabled": true,
  "mediaType": "BOOK",
  "lastScanAt": "2026-09-04T05:13:39.853Z",
  "scanStatus": "IDLE"
}
```

**BookScanStatusView**：
```json
{
  "scanStatus": "IDLE" | "SCANNING",
  "currentRootId": 1,                 // null if IDLE
  "startedAt": "2026-09-04T...",     // null if IDLE
  "lastScanAt": "2026-09-04T...",    // null if no scan ever
  "lastStats": "{\"added\":2,\"updated\":0,\"missing\":0,\"error\":0}"  // JSON 字符串
}
```

**扫描状态轮询**：触发扫描后**必须**轮询 `GET /api/book-roots/scan/status`（建议 1s 间隔）；
`scanStatus` 从 `SCANNING` 变 `IDLE` 时停止。`currentRootId` 标识当前正在扫的根。
**不要**用 `/api/scan/status`（那是 MUSIC 专用，M2-book 起已物理隔开）。

### 1.2 图书列表 `/api/books`

| 方法 | 路径 | 请求体 | 响应 | 用途 |
|---|---|---|---|---|
| GET | `/api/books` | query: `page, size, title?, author?, series?, libraryRootId?, isAvailable?` | `ApiResponse<PageResult<BookDto>>` | 分页 + 多字段过滤 |
| GET | `/api/books/{id}` | — | `ApiResponse<BookDto>` | 详情 |
| PATCH | `/api/books/{id}` | 见下 PATCH 白名单 | `ApiResponse<BookDto>` | 编辑元数据（不写回文件） |
| DELETE | `/api/books/{id}` | — | `ApiResponse<Void>` | 删 DB 行（**不删文件**） |

**分页参数**：
- `page` 0-based（不是 1-based，与 OPDS 的 page 1-based 不同）
- `size` 默认 20，限制 1–200（超过自动钳到 200）
- 响应信封：`{code: 0, message: "ok", data: {total, items: [...]}}`

**过滤参数（全部可选）**：
- `title` LIKE 匹配（大小写不敏感）
- `author` LIKE 匹配
- `series` LIKE 匹配
- `libraryRootId` 等于匹配
- `isAvailable` 等于匹配（boolean）

**BookDto**：
```json
{
  "id": 1,
  "title": "Test Book",
  "authors": "Author One & Author Two",
  "language": "en",
  "publisher": null,
  "pubDate": 2024,
  "description": null,
  "subject": "Fiction; Mystery",
  "identifier": "urn:uuid:...",
  "series": null,
  "seriesIndex": null,
  "rights": null,
  "format": "EPUB",                // EPUB | PDF
  "extension": "epub",
  "fileSize": 12345,
  "fileLastModified": "2026-09-04T05:13:39.853Z",
  "coverSource": "EMBEDDED",       // EMBEDDED | UPLOADED | null
  "coverUrl": "/opds/v1.2/catalog/1/cover",   // null if coverSource == null
  "isAvailable": true,
  "libraryRootId": 1,
  "createdAt": "2026-09-04T...",
  "updatedAt": "2026-09-04T..."
}
```

**`coverUrl` 是相对路径**（不是绝对 URL）。前端拼接 origin：
```ts
const coverUrl = book.coverUrl
  ? `${window.location.origin}${book.coverUrl}`
  : null;
```
**不要**用 `book.coverUrl` 直接渲染——缺协议/端口（KOReader 真机跨网络访问时会破图）。

### 1.3 PATCH `/api/books/{id}` 字段白名单

**可写字段**（Q28）：
| 字段 | 类型 | 备注 |
|---|---|---|
| `title` | string | 必填（Parser fallback 即是 fileName） |
| `authors` | string **或** string[] | 数组用 `String.join(" & ", list)` 拼接 |
| `language` | string | BCP-47 |
| `publisher` | string | |
| `pubDate` | integer | 1–9999（仅年份） |
| `description` | string | |
| `subject` | string **或** string[] | 数组用 `String.join("; ", list)` 拼接 |
| `identifier` | string | |
| `series` | string | |
| `seriesIndex` | double | 小数（1.0, 2.5, ...） |
| `rights` | string | |

**不可写字段**（提交 → 400 + code 1000）：
- `id` / `filePath` / `fileSize` / `fileLastModified` / `fingerprint` / `format` / `extension` / `libraryRootId` / `isAvailable` / `coverSource` / `createdAt` / `updatedAt` / `starredAt` / `rating`

**重要：`rating` 与 `starredAt` 在 Day-one 锁定**（Q24），不暴露 REST 写入；预留字段等 Day-two 接 KOSync 时再放。
前端表单**不要**渲染 rating/starredAt 编辑控件，否则用户提交会收 400。

### 1.4 封面 `/api/books/{id}/cover`

| 方法 | 路径 | 请求体 | 响应 | 用途 |
|---|---|---|---|---|
| POST | `/api/books/{id}/cover` | `multipart/form-data; file=@<bytes>` | `ApiResponse<Void>` | 上传替换封面 |
| DELETE | `/api/books/{id}/cover` | — | `ApiResponse<Void>` | 删封面（coverSource=null） |

**POST 限制**：
- `Content-Type` 必须在 `image/jpeg | image/jpg | image/png | image/gif` 内（大小写不敏感）
- 大小 ≤ 5MB
- 后端会自动等比缩放至 maxWidth=1200px + JPEG 编码
- `coverSource` 标 `UPLOADED`（优先级高于 EMBEDDED，下次扫描遇 EMBEDDED 不会覆盖）

**前端上传组件要点**：
```ts
const form = new FormData();
form.append('file', file);   // File 对象，浏览器自动设 Content-Type
await axios.post(`/api/books/${id}/cover`, form, {
  headers: { 'Content-Type': 'multipart/form-data' }
});
```
- 必须带 admin Basic（或 t/s 令牌，与现有 music 一致）
- 进度条用 axios `onUploadProgress`，刷新本地 `coverSource` 为 `UPLOADED` 即可

**DELETE 行为**：
- 物理删除 cover-source/book-{id}.jpg + cover-cache/book-{id}-*.jpg
- 设置 `coverSource=null`
- 下次扫描遇 EMBEDDED 抽取**自动重写**——前端不需要任何额外操作

### 1.5 通用约定（与 M1 一致）

- **认证**：`Authorization: Basic base64(admin:password)` 或 t/s 令牌（与现有 music 一致）
- **响应信封**：`{code: 0, message: "ok", data: <T>}`（M1 已约定）
- **业务错误码**：
  - `1000` 参数错误（如未知字段、字段类型错误）
  - `1001` 资源不存在（GET/PATCH/DELETE 不存在的 bookId）
  - `1002` 未认证
  - `1003` 权限不足
  - `1004` 冲突（重复路径）
  - `1100` 扫描进行中
  - `1200` 服务器内部错误
- **HTTP 状态码**（信封外层）：200 / 400 / 401 / 403 / 404 / 409 / 500
- **CORS**：`bifrost.cors.allowed-origins` 配置（默认 `*`，Vue Dashboard 在另一端口可直连）

## 2. 前端新增页面建议

按 M1 既有结构对齐，新增加 `/books` 路由区：

### 2.1 图书库根管理页 `/books/roots`

| UI 元素 | 数据源 |
|---|---|
| 库根列表表格（名称、路径、mediaType=BOOK badge、状态徽章、最后扫描时间） | `GET /api/book-roots` |
| 新建按钮 → 模态框（name、path 文本框 + "浏览" 文件系统选择） | `POST /api/book-roots` |
| 行内操作：编辑、删除、扫描 | PATCH / DELETE / `POST /api/book-roots/{id}/scan` |
| 顶部"扫描所有"按钮 | `POST /api/book-roots/scan/all` |
| 扫描状态条（顶部 / 抽屉）：轮询 `/api/book-roots/scan/status` | `GET /api/book-roots/scan/status` |

**复用 M1 `LibraryRootsPage`**：M1 已有 `/library-roots` 页面，建议**新建独立** `/books/roots` 页面
而不是扩展 M1 页面（ADR-0004 物理隔开原则同样适用前端）。共用 UI 组件（表格、模态框、扫描状态条）
通过组件抽取复用。

### 2.2 图书列表页 `/books`

| UI 元素 | 数据源 |
|---|---|
| 表格（封面缩略图、标题、作者、语言、系列、状态徽章、最后扫描时间） | `GET /api/books?page=0&size=20` |
| 过滤侧栏：title / author / series 输入框、libraryRootId 下拉、isAvailable 开关 | URL query 同步 |
| 分页器（page 0-based） | `total` / `items.length` |
| 行内操作：详情、编辑、删除、替换封面 | PATCH / DELETE / `POST /api/books/{id}/cover` |
| 顶部统计：当前过滤下 N 本书 | `total` |

**封面缩略图**：
```vue
<img
  v-if="book.coverUrl"
  :src="`${origin}${book.coverUrl}?size=64`"
  :alt="book.title"
  loading="lazy"
/>
<div v-else class="cover-placeholder">📖</div>
```
`size=64` 让后端生成 64px 缩略图（不走原图），减少带宽。

### 2.3 图书详情页 `/books/:id`

| UI 元素 | 数据源 |
|---|---|
| 标题、作者、语言、出版社、出版年、简介、主题、标识符、系列、版权 | `GET /api/books/{id}` 的 BookDto |
| 大封面图（点击放大） | `${origin}${book.coverUrl}` 不带 size（取原图） |
| 替换封面 / 删除封面按钮 | `POST /api/books/{id}/cover` / `DELETE /api/books/{id}/cover` |
| 文件元信息（路径、大小、最后修改） | BookDto 的 filePath / fileSize / fileLastModified |
| 来源（EMBEDDED / UPLOADED）徽章 | BookDto.coverSource |
| "下载文件" 按钮 | `<a :href="`${origin}/opds/v1.2/catalog/${id}/file`">`（用于管理员下载备份） |
| "编辑元数据" 按钮 → 模态框 | 提交 `PATCH /api/books/{id}` |

**编辑元数据表单**：
- 字段全部来自 BookDto 的可写子集
- `authors` / `subject` 用逗号分隔的输入框，提交时拆成数组（后端支持 `string[]`）
- 提交前客户端再做一次白名单校验，避免无谓 400

### 2.4 扫描状态全局组件 `<BookScanStatusBar>`

挂在 `App.vue` 顶部或侧栏，**任何页面**都能看到当前 BOOK 扫描进度。

```ts
// 每 1s 轮询
setInterval(async () => {
  const { data } = await axios.get('/api/book-roots/scan/status', { auth });
  if (data.data.scanStatus === 'SCANNING') {
    showProgressBar(data.data.currentRootId);
  } else {
    hideProgressBar();
  }
}, 1000);
```

**注意**：
- 必须在所有 `/api/book-roots` 操作完成后**继续轮询**直到 IDLE（扫描是异步的，触发后操作立即返回）
- `lastStats` 是 JSON 字符串，需要 `JSON.parse(data.lastStats).added` 拿上次统计

## 5. 端到端操作流（用户视角）

### 5.1 首次接入图书库

1. 进入 `/books/roots` → 点"新建" → 填 name + path（用文件选择器）→ 提交
2. 列表出现新行，状态 IDLE → 点"扫描"
3. 顶部扫描状态条出现，1s 后看到当前 root 编号和"扫描中"
4. 完成后状态条消失，列表行的"最后扫描时间"刷新
5. 切换到 `/books` 看到新书入库

### 5.2 编辑元数据

1. `/books` 列表 → 找到要编辑的书 → 点"编辑"
2. 模态框表单：title、authors（逗号分隔）、language 等
3. 提交 → 后端返回新 BookDto → 列表行更新
4. 提交错误（不可写字段）→ 表单显示错误，定位到字段

### 5.3 替换封面

1. `/books/:id` 详情页 → 看到大封面
2. 点"替换封面" → 弹出文件选择器 → 选 jpg/png/gif（≤5MB）
3. 提交 → 进度条 → 完成后详情页 coverSource=UPLOADED + 缩略图刷新
4. 错内容类型 / 超大 → 错误提示
