# 01 图书核心（实体 + 扫描 + Parser + Cover 抽取）

> 范围：M2-book mini-milestone 第 1 阶段。**物理隔开** music（ADR-0004）。本阶段结束 = 图书可扫描入库并能取到 cover；OPDS 输出与管理 REST 由 02/03 阶段消费。

## 阶段目标

- 实体 `Book` 入库，`LibraryRoot.mediaType` 列上线；
- 扫描器 `BookScanService` 可扫描启用根（仅 BOOK 类型），独立互斥锁、独立状态机；
- `BookParser` 注册表 + `EpubBookParser`（epublib）/ `PdfBookParser`（PDFBox）实现；
- `BookCoverService` 抽取 EPUB 封面（epublib `getCoverImage()`）和 PDF 封面（XMP 缩略图，**不渲染首页**），缓存到 `data/covers/cover-source/book-<id>.jpg`；
- `BookScanCompletedEvent` 发布（无消费者，预留 opds-publisher 缓存失效钩子）。

### T1.1 — `Book` 实体

```java
@Entity
@Table(name = "book",
       uniqueConstraints = @UniqueConstraint(name = "uk_book_path", columnNames = "filePath"))
class Book extends BaseEntity {
    // 文件（每书一文件）
    String filePath;                            // unique, NN
    Long fileSize;                              // NN
    Instant fileLastModified;                   // NN
    String fingerprint;                         // NN, path+size+mtime

    // 元数据
    String title;                               // NN
    String authors;                             // " & " 拼接
    String language;
    String publisher;
    Integer pubDate;                            // 仅年份
    String description;                         // TEXT
    String subject;                             // "; " 拼接
    String identifier;
    String series;
    Double seriesIndex;
    String rights;
    String format;                              // "EPUB" | "PDF"
    String extension;                           // "epub" | "pdf" | "kepub.epub"

    // 封面
    String coverSource;                         // "EMBEDDED" | "UPLOADED" | null

    // 扫描状态
    Boolean isAvailable;                        // NN, default true
    Long libraryRootId;                         // NN, FK

    // 收藏/评分（Day-one 不暴露 REST 写入）
    Instant starredAt;
    Integer rating;                              // 0-5, default 0
}
```

- `bifrost-domain` 新增 `BookRepository extends JpaRepository<Book, Long>` + 必要的查询方法（按 libraryRootId、按 isAvailable、分页 + title/authors/series 模糊）。

### T1.2 — `BookParser` 注册表 + EPUB/PDF 实现

```java
public interface BookParser {
    boolean supports(String extension);
    BookResult parse(Path file);                // 永不抛异常
}

public record BookResult(
    String title, String authors, String language, String publisher,
    Integer pubDate, String description, String subject, String identifier,
    String series, Double seriesIndex, String rights,
    byte[] embeddedCover,
    String format,
    boolean parseError
) {
    public static BookResult fallback(String fileName) { ... }
}

@Component
class BookParserRegistry {
    private final Map<String, BookParser> byExtension;
    Optional<BookParser> find(String ext);
    BookResult parse(Path file);
}
```

**`EpubBookParser`**（`com.positiondev.epublib:epublib-core:3.1`）：
- `EpubReader.readEpub()` 包装 try-catch；失败 → `BookResult.fallback(fileName)`
- `meta.getAuthors()` → 拼接 ` & `（trim/跳过空）
- `meta.getDates()` → 取第一个 → 取前 4 位 → `Integer.parseInt`
- `meta.getSubjects()` → 拼接 `; `
- `meta.getIdentifiers()` → 取第一个
- 系列：先看 `<meta name="calibre:series">`，fallback `<meta property="belongs-to-collection">`
- `book.getCoverImage().getData()` → `embeddedCover` bytes

**`PdfBookParser`**（`org.apache.pdfbox:pdfbox:3.0.x`）：
- 优先 XMP：`PDDocumentCatalog.loadXmpMetadata()` → XPATH 取 `dc:title/creator/...`
- fallback InfoDict：`PDDocument.getDocumentInformation()`
- 多作者 `Author` 字段 split（`; ` / `, ` 都试，trim 后非空去重）
- `embeddedCover = null`（**Day-one 不渲染首页**；Q31）

注册表路由：
```java
epub       -> EpubBookParser
kepub.epub -> EpubBookParser
pdf        -> PdfBookParser
```

### T1.3 — `BookScanService`

```java
@Service
class BookScanService {
    private final ReentrantLock bookScanLock = new ReentrantLock();
    private final ApplicationEventPublisher events;

    public BookScanStats scanAll(boolean force) { ... }
    public BookScanStats scanRoot(Long rootId, boolean force) { ... }
    public BookScanStatusDto getStatus() { ... }
}
```

- 加锁（tryLock），失败 → `BizException(BIZ_SCAN_IN_PROGRESS, 1100)`
- 遍历 `LibraryRootRepository.findByEnabledTrueAndMediaType(BOOK)`
- 每个 root 标 `scanStatus=SCANNING`
- `Files.walk` 过滤 `BookParserRegistry.find(extension).isPresent()`
- 路径→Book 索引（`bookRepository.findByLibraryRootId(rootId)`）
- 对每个 file：
  - 算 fingerprint（复用 `Fingerprint.of(path, size, mtime)`）
  - 查 dbIndex：match + fingerprint 一致 + isAvailable → 跳过
  - 否则 → `BookParserRegistry.parse(file)` → 累积 pending
  - 批大小 200（`TransactionTemplate`）commit
- 缺失的旧 file（增量模式） → `isAvailable=false`（保留记录，文件丢失）
- force=true → 缺失的旧 file → DELETE（按 Day-one 决策：book 不级联引用，DELETE 直接清）
- 标 root `scanStatus=IDLE, lastScanAt, lastScanStats=JSON`
- 发布 `BookScanCompletedEvent(rootId, stats)`
- 解锁，发布最终 `BookScanCompletedEvent(null, totalStats)`

事件定义（`bifrost-core/src/main/java/com/bifrost/core/book/event/`）：
```java
public record BookScanCompletedEvent(Long libraryRootId, BookScanStats stats) {}
```

`BookScanStateResetRunner`（`ApplicationRunner`）启动时把残留 `SCANNING` 标回 `IDLE`（与 music 同模式）。

### T1.4 — `BookCoverService`

```java
@Service
class BookCoverService {
    void storeEmbeddedCover(Book book, byte[] bytes);     // 写 cover-source/book-<id>.jpg
    void storeUploadedCover(Book book, byte[] bytes);     // 写 cover-source/book-<id>.jpg + coverSource=UPLOADED
    void deleteCover(Book book);                          // 删文件，coverSource=null
    Optional<byte[]> coverBytes(Long bookId, Integer size); // 读缩略图或原图
    boolean hasCover(Book book);                          // coverSource != null && 文件存在
}
```

布局沿用 music `bifrost.media.cover-cache-dir` 配置（`./data/covers`）：
- `cover-source/book-<id>.jpg`（原图，仅 EMBEDDED / UPLOADED 区分）
- `cover-cache/book-<id>-<N>.jpg`（缩略图，按 64/200/默认 nearest 三档，与 music `al-<id>` 同模式）

Day-one 缩略图简化：仅做原图 + 一种 size（200）；多 size bucket 留 Day-two。

`BookScanCompletedEvent` 监听器：扫描完成后调用 `bookCoverService.deleteMissingCovers()`（清理 DB 删了但磁盘残留的 cover-source 文件；Day-two 优化）。
