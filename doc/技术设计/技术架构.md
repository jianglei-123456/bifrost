## 1. 项目概述

家庭媒体库管理平台，统一管理三类媒体资源：

| 媒体类型 | 核心能力 | 所在包 |
| --- | --- | --- |
| 视频 video | 媒体扫描、索引 | `com.bifrost.core.video` |
| 音频 audio | 标签解析 | `com.bifrost.core.audio` |
| 电子书 book | 元数据解析 | `com.bifrost.core.book` |

对外集成：向 **Jellyfin** 推送/同步、向 **Sonic** 推送、生成图书 **OPDS** 流；`bifrost-api` 提供 RESTful API 供 Vue Dashboard 调用。

## 2. 技术栈（最终确定）

| 项 | 选择 |
| --- | --- |
| 语言 | Java 21（编译目标 `maven.compiler.release=21`） |
| 框架 | Spring Boot 3.5.16（Spring Framework 6.2.19） |
| 构建 | Maven 多模块，父工程 `spring-boot-starter-parent` 3.5.16 |
| 坐标 | `com.bifrost:bifrost:1.0.0-SNAPSHOT`，基础包名 `com.bifrost` |
| 工程化 | Lombok（父 POM 统一，optional + annotationProcessorPaths）、Maven Wrapper 3.9.9 |
| 依赖 | 仅基础 starter + test；bifrost-api 额外引入 spring-boot-starter-web；未引入 JPA/Redis/MyBatis/actuator |

## 3. 模块架构

```
bifrost (父级 POM，统一版本)
├── bifrost-common        # 工具包：字符串、日期、文件 IO、自定义异常（纯 Java，无 Spring）
├── bifrost-domain        # 实体（Entity）、DTO、枚举、Repository 接口
├── bifrost-core          # 核心业务（Service 层），包隔离 video / audio / book
├── bifrost-adapter       # 对接外部客户端（聚合 POM）
│   ├── jellyfin-client   # Jellyfin 推送/同步适配器
│   ├── sonic-client      # Sonic 推送适配器
│   └── opds-publisher    # 图书 OPDS 流生成适配器
├── bifrost-api           # RESTful Controller 层（供 Vue Dashboard 调用）
└── bifrost-bootstrap     # 启动类 + application.yml，生成可执行 jar
```

**依赖关系（单向，禁止反向/循环）**：

```
bifrost-common ◄── bifrost-domain ◄── bifrost-core ◄── bifrost-adapter（聚合，子模块继承）
bifrost-core ◄── bifrost-api ◄── bifrost-bootstrap
```

**包约定**：基础包 `com.bifrost.*`；core 内 `com.bifrost.core.{video,audio,book}` 包隔离；adapter 子模块 `com.bifrost.adapter.{jellyfin,sonic,opds}`。

## 4. 关键技术设计

- **跨模块扫描**：启动类 `@SpringBootApplication(scanBasePackages = "com.bifrost")`，保证各模块 Controller/Service 注册到容器。
- **版本统一**：第三方依赖由 spring-boot-starter-parent 管理；内部模块在父 POM dependencyManagement 声明为 `${project.version}`，子模块不写版本号。
- **打包策略**：仅 bifrost-bootstrap 配置 spring-boot-maven-plugin 生成可执行 fat jar，其余模块保持普通 jar。
- **健康检查**：`bifrost-api` 提供 `GET /api/ping` → `pong`。

## 5. 构建与运行

```bash
./mvnw clean verify                                  # 全量构建
./mvnw -pl bifrost-bootstrap -am spring-boot:run     # 启动，端口 8080
```

验证：`curl http://localhost:8080/api/ping` → `pong`
