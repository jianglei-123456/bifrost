# M1 里程碑任务总览（Bifrost 音乐管理 + 通用底座）

| 项 | 内容 |
| --- | --- |
| 里程碑 | M1（v1）：通用能力 + 音乐管理 + 管理 REST + Subsonic 服务（Syrinx） |
| 本轮范围 | 不含 Docker（Q7-B 延后，见 07-延后项） |
| 依据 | 功能设计三篇、技术设计两篇、Subsonic_API_参考、ADR-0001~0003 |
| 交付形态 | 分 6 个任务阶段推进，每阶段可编译、可测试、可提交；最终一次交付完整 M1 |

## 1. 验收标准（对齐《项目整体功能说明》M1）

1. 扫描 MP3/FLAC/M4A 目录建库，形成「艺术家 / 专辑 / 曲目」三层索引；
2. Subsonic 客户端（Feishin / DSub / Symfonium 等）可连接、浏览、搜索、播放、收藏、评分、建歌单；
3. `/api/**` 管理契约可用（统一信封、认证、分页）；
4. 文档齐备：任务文档 + ADR + hurl 契约测试 + 构建全绿。

## 2. 阶段与依赖

```
01 通用底座 ──► 02 音乐核心 ──► 04 管理 REST
        │            │
        └──► 03 统一认证 ──────┴──► 05 Subsonic (Syrinx)
06 测试与收尾（贯穿各阶段；hurl 契约测试自 03 起可运行）
07 延后项（Docker 等，本轮不做）
```

- 01 → 02：音乐核心依赖实体 / 仓储 / 持久化 / 配置；
- 01 → 03：认证依赖 User 实体与配置体系；
- 02 → 04、02 → 05：管理 REST 与 Subsonic 均消费音乐核心服务；
- 03 → 04、03 → 05：两个入口的认证（Spring Security）；
- 每阶段完成标准：`./mvnw -pl <模块> -am compile` 通过 + 该阶段测试通过 + git 提交。
