# 02 音乐核心

> 目标：bifrost-core `com.bifrost.core.audio` 包：标签解析、扫描引擎、聚合、拼音索引、封面、播放统计/收藏/评分、歌单、nowPlaying、查询服务。依据：《音乐管理技术设计》§3–§5、§7、§8；《音乐管理功能说明》§2–§7。core 无 web/持久化依赖（仅 `spring-boot-starter`）。
> 完成标准：单测覆盖标签/聚合/拼音；集成测试覆盖扫描（新增/变更/缺失/幂等/互斥）；可用测试目录真实建库。

## T2.1 标签解析（AudioTagParser）

- `parse(Path) → TagResult`，按扩展名分发：mp3→ID3、flac/m4a→Vorbis/MP4、wav→无标签兜底；
- jaudiotagger **3.0.1**（ADR-0002）`AudioFileIO.read` → 字段抽取，映射表对齐《音乐管理功能说明》§2.2（TIT2/TITLE/©nam、TRCK/TRACKNUMBER/trkn、TPOS/DISCNUMBER/diskn、TPE1/ARTIST/©ART、TPE2/ALBUMARTIST/aART、TALB/ALBUM/©alb、TDRC/TYER/DATE/©day、TCON/GENRE/©gen、APIC/METADATA_BLOCK_PICTURE/covr）；
- 规范化：trim；空值置 null；year 解析失败置 null；流派取首个；
- 文件名兜底：无标题 → 去扩展名文件名；无艺术家 → 不参与艺术家聚合（"未知艺术家"，Q9）；
- 封面：内嵌图（取首个）> 目录 `cover.jpg`/`folder.jpg`（Q13 只用于专辑，见 T2.6）；
- **只读**：仅 `read`，绝不写回；解析异常 → 记录错误计数 + 仅文件名兜底结果。

## T2.2 专辑键规范化

- `normalize = trim + 大小写折叠(lowercase)`；
- 专辑键 = `normalize(albumArtistName) + "|" + normalize(albumTitle)`；albumArtist 缺省回退 track artist；
- 多碟合并（discNo 默认 1）；合辑按标签字面值（"Various Artists" 原样）；v1 不做模糊匹配。

## T2.3 拼音索引

- jpinyin 1.1.8 `PinyinHelper.getShortPinyin`；
- indexLetter 算法：ASCII 字母 → 大写；汉字 → 拼音首字母（失败 '#'）；其他（日文/数字/符号）→ '#'；
- 扫描聚合时计算并持久化 Artist.indexLetter；查询按字段分组排序。

## T2.4 扫描引擎（ScanService）

- 全局互斥：JVM 内 ReentrantLock + 状态位（`SCANNING` 时再次触发 → "扫描进行中"）；
- 遍历库根，过滤支持扩展名（mp3/flac/m4a/wav）；多根串行；
- 指纹比对：`dbIndex = findByLibraryRootId → path→Track`；指纹一致跳过；新增 parseAndInsert；变更 parseAndUpdate；剩余记录 → `isAvailable=false`（缺失，保留记录）；
- 事务：200 文件/批提交（`bifrost.scan.batch-size`）；
- 聚合刷新：仅本次涉及专辑/艺术家增量刷新；
- 启动时重置残留 `SCANNING → IDLE`；
- 完成后更新 root.scanStatus/lastScanAt/lastScanStats，发布 `ScanCompletedEvent`；
- 触发入口：管理 REST（T4.x）、Subsonic startScan（T5.x）、定时 `@Scheduled`（cron 置空禁用）。

## T2.5 聚合服务（AggregationService）

- Artist / Album **find-or-create**（Q10）：按规范化键查询，存在则复用（跨库根全局合并）；
- 无署名曲目：不创建 Artist（Q9），Track.artistId/artistName 为空；
- Album 字段聚合：duration、playCount、year（取首个非空）、genre（取首个）、coverSource、曲目数；
- Artist 字段：albumCount（含虚拟分组统计口径）、indexLetter；
- 专辑 artistId：有 albumArtist → 其 Artist；否则首个曲目艺术家（可空）。

## T2.6 封面（CoverService）

- 入库时：内嵌图抽取存 `cover-source/al-<id>.jpg`；无内嵌 → 目录图路径记录于 coverSource；
- 缩略图：`getCoverArt?size=N` → `cover-cache/al-<id>-<N>.jpg`（原图/200/64 按需生成，size 映射最近档位）；
- 失效：扫描更新专辑封面时清除对应缓存文件；
- v1 无 LRU 上限（可增强）。

## T2.7 播放统计 / 收藏 / 评分

- `playCount`/`lastPlayed` 仅 `scrobble(submission=true)` 落库（Track；Album/Artist 聚合口径同步）；
- 收藏：Track/Album/Artist 三态 `starredAt`（Q14，starred = starredAt != null）；管理 REST + Subsonic star/unstar 共用；
- 评分：`rating` 1–5（0=取消）；
- nowPlaying：记录（用户、曲目、开始时间），来源 = stream 开始 + `scrobble(submission=false)`（Q20）；进程内存储。

## T2.8 歌单（PlaylistService）

- CRUD；条目增删/排序（position 唯一于歌单内维护）；
- owner=admin、public=true（v1）；comment 字段（Q18）；
- 曲目缺失（isAvailable=false）时歌单引用保留，隐藏展示。

## T2.9 未知艺术家虚拟分组

- 查询辅助：artistName 为空（或 null）的曲目在展示层归入"未知艺术家"分组（Q9）；
- 分组字母：`#`（Q16）；该分组含其专辑与曲目，可被浏览/搜索（曲目搜索不因无艺术家被排除）。

## T2.10 查询服务（供 04/05 共用）

- 艺术家：按 indexLetter 分组 + 名称排序；详情含专辑（按年份，缺失排后 → 标题）；
- 专辑：列表（类型过滤：随机/最新/最高/常播/最近/字母/收藏/年份/流派）+ 详情（曲目按 discNo → trackNo → 文件名）；
- 曲目：列表/详情；
- 搜索：query 匹配艺术家/专辑/曲目（标题），支持按库根过滤；
- 缺失文件（isAvailable=false）对浏览/搜索隐藏（管理端可查，可手动清理）。
