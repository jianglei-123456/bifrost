# 06 测试与收尾

> 目标：全层自动化测试 + hurl 端点契约测试 + 构建全绿 + 文档收尾（Q6-A）。依据：《音乐管理技术设计》§11。
> 完成标准：`./mvnw clean verify` 全绿；`hurl --test hurl/rest/*.hurl hurl/api/*.hurl` 全绿。

## T6.1 单元测试

- 标签解析：**程序化生成**最小样本 MP3（ID3v2.3/2.4）/FLAC（Vorbis）/M4A（MP4）文件（含中文标签、多碟、合辑、无标签、解析失败兜底）；字段抽取、缺省回退、文件名兜底、封面抽取；
- 聚合：专辑键规范化、多碟合并、跨库根全局合并、缺失标记、重复扫描不产生重复实体（Q10）；
- 拼音：中文/拉丁/日文/符号/多音字（重庆、单、曾）→ 分组正确；'#' 兜底；
- 认证：AES-GCM 加解密往返、md5(password+salt) 令牌、恒定时间比较路径、enc: 解码。

## T6.2 集成测试

- 持久化：SQLite 内存/临时文件 CRUD、唯一约束（Track.filePath/Artist.name/User.username/PlaylistEntry position）、批量提交；
- 扫描：增量（新增/变更/缺失）、幂等重扫、全局互斥（并发触发 → 扫描进行中）；
- 上下文启动：`@SpringBootTest` 应用可启动（含 SQLite 初始化）。

## T6.3 hurl 端点契约测试（先写文件，后跑）

- 目录：`hurl/rest/*.hurl`、`hurl/api/*.hurl`、`hurl/README.md`、`hurl/setup.hurl`（可选：认证辅助）；
- `hurl/README.md`：启动应用命令、认证 token 生成方法（md5 公式示例）、运行方式（`hurl --test`）、环境变量（密码/BASE_URL）；
- `hurl/rest/`：按端点分组：`auth.hurl`（40/10/42/43 + 双格式）、`browsing.hurl`、`lists.hurl`、`search.hurl`、`playlists.hurl`、`media.hurl`（stream Range/206、download、getCoverArt）、`annotation.hurl`（star/rating/scrobble）、`scanning.hurl`、`system.hurl`（ping/getLicense/getOpenSubsonicExtensions 免认证）、`user.hurl`；
