# 01 通用底座

> 目标：bifrost-common 工具、bifrost-domain 实体/仓储/枚举、SQLite+JPA 持久化、配置体系、日志、统一异常与响应、事件机制、健康检查、数据目录初始化。依据：《通用功能说明》§2–§7、§11、§12；《整体技术架构》§5、§6；《音乐管理技术设计》§1、§2。
> 完成标准：`./mvnw -DskipTests compile` 通过；Spring 上下文启动成功；`/api/ping` 返回 `pong`；SQLite 文件生成、schema 由 `ddl-auto=update` 建表；实体字段与设计文档（含修正项）一致。

## T1.1 bifrost-common 工具包（纯 Java，无 Spring）

- 字符串工具：trim/空值处理、大小写折叠（聚合键用）；
- 日期工具：Instant ↔ 毫秒、ISO-8601 输出；
- 文件 IO 工具：扩展名提取、目录遍历过滤、文件大小/mtime 读取；
- 指纹工具：`path + size + mtime` 拼接（变更检测）；
- 自定义异常：`BizException(code, message)`；
- 常量：业务错误码（1000 参数错误、1001 资源不存在、1002 未认证、1003 无权限、1004 冲突/状态非法、1100 扫描进行中、1200 内部错误；2000+ 音乐领域预留）。

## T1.2 配置体系

- `@ConfigurationProperties` 强类型配置类（前缀 `bifrost.*`）：
  - `bifrost.db.path`（默认 `./data/bifrost.db`）
  - `bifrost.library.roots[]`（name/path/enabled）
  - `bifrost.media.cover-cache-dir`（默认 `./data/covers`）
  - `bifrost.scan.cron`（默认 `0 3 * * *`）、`bifrost.scan.batch-size`（200）
  - `bifrost.auth.initial-username`（admin）
  - `bifrost.subsonic.enabled`（true）、`bifrost.subsonic.api-version`（1.16.1）
- `bifrost-bootstrap/src/main/resources/application.yml` 写入完整默认配置（含 spring.jpa、spring.datasource.url 带 `?journal_mode=WAL&busy_timeout=5000`）；
- 数据目录（`./data`）启动时自动创建。

## T1.3 日志

- Logback：控制台 + `logs/` 按日滚动文件（保留策略可配置）；
- `com.bifrost` 关键流程（扫描/认证）INFO/DEBUG 级别可调；
- 错误统一由全局异常处理器记录（不散落 log.error）。

## T1.4 统一响应与异常（/api/**）

- 响应信封 `{code, message, data}`（code=0 成功）；
- 全局 `@RestControllerAdvice`：BizException → 对应业务码；未知异常 → 500 + code 1200；
- HTTP 状态映射：400/401/403/404/500；
- 分页约定：`page`（0 起）/`size`（默认 20，最大 200）→ `{total, items}`；时间 ISO-8601 UTC。

## T1.5 实体与仓储（bifrost-domain）

- 实体：Artist、Album、Track、LibraryRoot、User、Playlist、PlaylistEntry，字段严格对齐《音乐管理技术设计》§1，**含修正项**：
  - Artist 增补 `starredAt`(Instant 可空)、`rating`、`playCount`、`lastPlayed`（ADR-0001 + Q14）；
  - Playlist 增补 `comment`（Q18）；
  - 各实体 `createdAt`/`updatedAt`(Instant)；Track 含 `fingerprint`、`isAvailable`、`libraryRootId`；
  - **所有字段带中文注释**（注释文本与设计文档一致）；
- 枚举：MediaType(MUSIC/VIDEO/BOOK)、ScanStatus(IDLE/SCANNING)、UserRole(ADMIN)；
- 唯一约束：Track.filePath、Artist.name、LibraryRoot.path、User.username、PlaylistEntry(playlistId, position)；Album 不加唯一约束（Q10）；
- Repository 接口（Spring Data）：ArtistRepository、AlbumRepository、TrackRepository、LibraryRootRepository、UserRepository、PlaylistRepository、PlaylistEntryRepository（按需派生查询：findByLibraryRootId、findByFilePath、findByName 等）。

## T1.6 SQLite / JPA 持久化

- `hibernate-community-dialects` 的 `SQLiteDialect`；`spring.jpa.hibernate.ddl-auto=update`；
- WAL + busy_timeout（连接串）；`PRAGMA foreign_keys=ON`（启动初始化）；
- Instant → 毫秒 INTEGER 存储（统一便于排序）；
- 事务边界在 core Service（`@Transactional`）；
- 启动时 SQLite 可读写校验（失败 → 启动失败并给出明确日志）。

## T1.7 事件机制

- `ScanCompletedEvent(libraryRootId, stats{added,updated,missing,error})`；
- 基于 `ApplicationEventPublisher` 同步发布；
- 预留 `TrackUpdatedEvent`（本轮不发布）。
