# 07 延后项（本轮不做）

> 记录 M1 明确延后/不做的内容，防止实现时误入。所有"可增强"清单详见各文档末章，此处仅收录与 M1 直接相关者。

## 7.1 Docker 部署（Q7-B）

- `docker/Dockerfile`（多阶段：maven:3.9-eclipse-temurin-21 → eclipse-temurin:21-jre）与 `docker/docker-compose.yml`（卷挂载 ./data、BIFROST_AUTH_INITIAL_PASSWORD 必填、healthcheck `/api/ping`）**延后**，待代码稳定后补充（《整体技术架构》§9.1 为规划）；
- README Docker 段落同步标注「延后」。

## 7.2 本轮明确不做（对齐《项目整体功能说明》§5 非目标）

- 不转码（maxBitRate/format/timeOffset 接收但忽略）；
- 不写回标签（只读解析）；
- 不在线刮削；
- 不做视频/电子书（仅包结构与 MediaType 预留）；
- 不引入 Redis/MyBatis/WebFlux/Actuator；
- 不做多用户（v1 单管理员，表结构预留）；
- 不做音频指纹去重；
- 不做专辑 zip 下载（download 非歌曲 ID → 70）。

## 7.3 音乐可增强（后续里程碑候选）

文件系统监听（WatchService）、在线刮削（MusicBrainz/Last.fm）、动态歌单、播放历史明细、多用户+Subsonic 角色映射、API Key 认证（apiKeyAuthentication + tokenInfo）、播放队列（playQueue/bookmark）、结构化歌词（getLyricsBySongId + songLyrics 扩展）、元数据编辑写回、音频指纹去重、拼音纠错表、碟标题支持、WMA/APE、自动清理缺失、专辑/艺术家/歌单 zip、封面 LRU 上限、艺术家封面。

## 7.4 通用可增强

数据库迁移工具（Flyway/Liquibase 替代 ddl-auto=update）、Actuator/Prometheus 指标、扫描并发（多库根并行/断点续扫）、异步事件、中央日志收集、管理端 UI（另一项目）。
