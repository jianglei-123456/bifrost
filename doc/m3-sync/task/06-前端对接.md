## 1. 端点清单（10 个）

| # | 方法 | 路径 | 用途 |
|---|---|---|---|
| 1 | GET | `/api/book-sync/account` | 读同步账号（**含明文口令**）与展示用 `serverUrl` |
| 2 | PUT | `/api/book-sync/account` | 改用户名 / 口令（`{username?, password?}`） |
| 3 | POST | `/api/book-sync/account/password` | 生成随机口令并返回（明文） |
| 4 | GET | `/api/book-sync/progress` | 进度列表（分页 + 过滤） |
| 5 | DELETE | `/api/book-sync/progress/{id}` | 删除（重置）单条进度 |
| 6 | GET | `/api/book-sync/orphans` | 孤儿进度列表（含建议绑定） |
| 7 | POST | `/api/book-sync/orphans/{id}/bind` | 人工绑定 `{bookId}` |
| 8 | POST | `/api/book-sync/orphans/{id}/rematch` | 人工重新匹配一次（`data.matched` 可能是 false） |
| 9 | POST | `/api/book-sync/orphans/{id}/ignore` | 忽略 / 取消忽略 `{ignored}` |
| 10 | GET | `/api/book-sync/devices` | 设备列表（不分页） |
| 11 | GET | `/api/book-sync/stats` | 页面头部统计 |

（字段级样例见 `doc/m3-sync/task/03-管理REST.md` 各小节。）

## 2. 页面建议

**路由 `/books/progress`，菜单放「图书」分组**（C3 决策），与「图书」「图书库」并列。页内建议三个区块：

1. **同步账号卡片**（页面顶部）
   - 展示 `serverUrl`（可复制）、用户名、口令（默认打码，点"显示"看明文）、`registrationEnabled` / `autoScanOnUnmatched` 状态；
   - 动作：改用户名、改口令、**生成随机口令**；
   - **必读提示文案**（否则用户会踩坑）：
     - KOReader 里填地址要**手动把默认的 `https://` 改成 `http://`**（协议不自动补 scheme）；
     - 设备上点 Register 或 Login 都行；
     - **改口令后已配置的设备需要重新登录**（旧凭据会被拒绝）；
     - 设备上 `Document matching method` 要保持在 **Binary**。
2. **进度列表**（主区）
   - 列：封面缩略图 + 书名/作者、进度百分比（进度条）、设备名、最后上报时间；行内动作："重置进度"（危险操作需二次确认）；
   - 过滤：书名模糊、设备、图书目录、仅看孤儿；
   - **重置进度的确认文案必须写明**："只删除服务器上的记录；设备本地位置不变，设备下次推送会重新建立记录。"
3. **孤儿页签**（次区，或与"设备"并列为 tab）
   - 列：文档指纹（前 8 位 + 可复制全文）、百分比、设备、首次出现时间、"已尝试匹配"标记、建议绑定的书；
   - 动作：绑定到指定书（书选择器复用 `/api/books` 搜索）、重新匹配、忽略/取消忽略；
   - "未结算"（`scanAttemptedAt == null`）用角标提示——正常是极短窗口，长挂说明自动扫描被跳过或失败。
4. **设备列表**（tab 或折叠区）
   - 列：设备名、`device_id`（可复制）、首见/末见时间、上报次数；
   - **不要做"踢设备"按钮**（协议层没有会话，无法封锁单设备）；文案上引导用户"改口令"来使所有设备重新登录。

## 3. 状态与刷新

- **不需要高频轮询**（与图书扫描不同）：进入页面加载 + 变更后局部刷新 + 顶部手动刷新按钮即可。
- 进度数据由设备推送驱动，**管理端读到的可能滞后**（客户端 10s/25s 去抖 + 关书才推送），页面上不要显示"实时"之类的措辞。
- 管理端的时间字段（`reportedAt` / `createdAt` / `scanAttemptedAt` / `firstSeenAt` / `lastSeenAt` / `lastReportedAt`）都是 **ISO-8601 字符串**，与 `/api/books` 的 `createdAt` 一致，直接用 `utils/format.ts` 的 `formatDateTime`。唯一带**秒级 epoch** 的是 **KOSync 协议端点**响应里的 `timestamp`（给 KOReader 用的，Dashboard 不接触）。

## 4. 契约测试

后端 hurl 契约：`hurl/api/book-sync.hurl`、`hurl/kosync/*.hurl`（`powershell -File hurl\run.ps1`）。Dashboard 侧建议对 `/api/book-sync/**` 加一层 vitest + msw 的契约快照，避免后端字段改名时静默坏掉。
