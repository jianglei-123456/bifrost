# Bifrost Dashboard 设计系统 —「深空聆听室 · 彩虹桥」

> 设计方向已与用户确认（Q3 选 A）。本文档是实现的单一事实源：`src/styles/tokens.css` 的每个变量都来自这里。

## 1. 主题陈述（Thesis）

Bifrost 是联通音乐 / 影音 / 图书的彩虹桥（北欧神话联通九界的彩虹桥）。v1 交付音乐，但设计必须能自然延伸到视频海报与书封。**「深空聆听室」**：深空中性底让"封面即内容"成为视觉主角 —— 无论封面来自哪类媒体，UI 不动，换的只是封面来源。彩虹光谱只作为签名出现（品牌、登录拱桥、导航激活线），其余全部安静。

## 2. 色彩（6 个具名色 + 光谱）

| 变量             | 值                                                               | 用途                                                  |
| ---------------- | ---------------------------------------------------------------- | ----------------------------------------------------- |
| `--ink`          | `#0B0E14`                                                        | 深空底 · 页面背景                                     |
| `--panel`        | `#12161F`                                                        | 面板 · 卡片 / 侧栏 / 表格                             |
| `--panel-raised` | `#1A2130`                                                        | 浮起层 · hover / 弹层 / 激活态底                      |
| `--line`         | `#1E2636`                                                        | 分隔线 / 描边（1px）                                  |
| `--text`         | `#E9EDF5`                                                        | 主文字                                                |
| `--text-dim`     | `#98A2B3`                                                        | 次要文字 / 说明 / 占位                                |
| `--spectrum`     | `linear-gradient(90deg,#FF5D73,#FFB454,#3DDC97,#4CC9F0,#7B6CFF)` | **签名光谱** · 品牌 / 拱桥 / 激活线 / 焦点环 / 空状态 |

- 语义色复用光谱端点：`--success:#3DDC97`、`--danger:#FF5D73`、`--warn:#FFB454`、`--info:#4CC9F0`，保证整站色相收敛在光谱内。
- 封面在深色底上自然发光，无需额外阴影；卡片 hover 仅 1px 提亮 + 轻微上移。

## 3. 字体（3 个角色）

| 角色    | 字体                                                                                                   | 用途                                             |
| ------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| Display | **Space Grotesk**（拉丁/数字）+ 中文系统黑体回退                                                       | 页面标题、品牌、大数字、统计主角 —— 克制的科技感 |
| Body    | 系统栈：`-apple-system, "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", "Segoe UI", sans-serif` | 正文 / 表单 / 表格                               |
| Mono    | **JetBrains Mono**                                                                                     | 数据：时长、码率、采样率、文件大小、时间戳、ID   |

- 字阶：`12` 说明 / `13` 次要 / `14` 正文 / `15–16` 卡片标题 / `20` 页面标题 / `28` 统计数字 / `34` 登录页主标题。
- 数字（时长、统计）一律 Mono + tabular-nums，避免跳动。

## 4. 布局

固定左侧栏 232px + 顶栏 + 内容区（最大宽 1400px 居中）。

```
┌──────────────┬────────────────────────────────────┐
│ Bifrost ✦    │ 媒体浏览        [扫描中 ● 呼吸灯]  │  ← 顶栏：页标题 + 扫描状态 + admin
│ ──────────── │────────────────────────────────────┤
│ 音乐         │  页面标题 + 副标题        [+ 操作]   │
│  总览        │ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐   │
│  艺术家      │ │封面 │ │封面 │ │封面 │ │封面 │   │  ← 封面网格（AlbumGrid）
│  专辑        │ │     │ │     │ │     │ │     │   │
│  曲目        │ └─────┘ └─────┘ └─────┘ └─────┘   │
│  搜索        │                                     │
│  歌单        │  曲目表格：封面缩略 + 标题 + Mono 数据 │
│  音乐库      │  时长 码率 格式   [收藏][评分★]       │
│ ──────────── │                                     │
│ 图书         │                                     │
│  图书        │                                     │
│  图书库      │                                     │
│ ──────────── │                                     │
│ 系统         │                                     │
│  账号        │                                     │
│  系统信息    │                                     │
│ ──────────── │                                     │
│ 影音         │                                     │
│  (即将联通)  │                                     │
└──────────────┴────────────────────────────────────┘
```

- 侧栏按 **媒体类型分区**（音乐 / 图书 / 影音预留），兑现"彩虹桥联通一切"的品牌承诺；未交付分区置灰 `即将联通`。每类的「库」页把目录管理与扫描合二为一（音乐库 / 图书库）。
- 激活项：左侧 2px 光谱渐变竖线 + `--panel-raised` 底（签名元素的日常形态）。
- 内容卡片：`--panel` 底 + 1px `--line` 描边 + 圆角 10px；封面网格 `repeat(auto-fill, minmax(160px, 1fr))`。
- 响应式：<1024px 侧栏收为图标栏；封面网格自动降列。

## 5. 签名元素：「桥」

大胆只花在一处 —— 彩虹拱桥：

1. **登录页**：页面底部升起一道光谱渐变拱桥（SVG 弧 + 柔和辉光），配合 `Bifrost · 联通一切` 主标题 —— 唯一的戏剧性时刻。
2. **侧栏品牌**：拱桥弧线 + 「Bifrost」字标；导航激活线复用同一光谱。
3. 空状态：细光谱下划线 + 一句引导文案（如"添加第一个音乐目录，架起你的桥"）。

## 6. 动效（克制）

- 内容卡片入场：200ms 淡入 + 8px 上移（stagger 40ms）；`prefers-reduced-motion` 全部关闭。
- 扫描状态：SCANNING 时顶栏呼吸灯脉冲（2s 循环）；IDLE 常亮灰点。
- 封面 hover：+1px 提亮、上移 2px；不做环境频谱动画（方案 C 已否决：影音/图书没有频谱可律动）。

## 7. 文案基调

主动语态、句子式大小写、中文界面；动作按钮 = 动作本身（"保存修改"而非"提交"）；空状态是邀请而非道歉；错误不道歉、不模糊（"口令错误"而非"登录失败"）。品牌词一律「彩虹桥 / Bifrost」。

## 8. 唯一性自查（对照模板）

- ❌ 奶油底 + 衬线 + 陶土红（否决）· ❌ 纯黑 + 荧光绿（否决）· ❌ 报纸式细线排版（否决）
- ✅ 深空中性 + 封面主角 + 五色光谱只做签名 —— 光谱来自产品真名（彩虹桥）而非装饰；数据 Mono 强化"媒体档案"感；影音/图书预留分区把品牌承诺变成信息架构。这些是该简报独有的选择。
